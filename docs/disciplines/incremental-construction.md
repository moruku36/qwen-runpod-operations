# 段階的構築の規律

対象: 数百行規模の長い成果物(Markdown記事、設計書、コード)。一気に書き下ろさない。

1. **構成確認**: 見出し構成と各節の目的、読み手を先に決めて共有する。
2. **セクション単位の執筆**: 1節ずつ書く。節ごとに、前節との用語・数値の一貫性を確認する。
3. **事実照合**: 節を書いたら、数値・ステータス・コマンドを一次ソースと照合する(`docs/disciplines/writing-and-verification-guide.md`)。
4. **全体確認**: 最後に通読し、重複・矛盾・未確認事項の明記漏れを直す。

コードの場合は、節をモジュール・関数に読み替え、各段階でテストか実行確認をする。未実行の確認は「未実行」と書く。
